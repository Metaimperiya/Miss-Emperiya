Глава 01

Что такое сайт и как он работает

Сайт — это набор файлов, которые лежат на специальном компьютере (сервере) и которые любой человек может открыть в браузере. Представь, что у тебя есть папка с фотографиями, текстами, кнопками и ссылками. Ты выкладываешь эту папку в интернет — и теперь любой человек в мире может её открыть. Это и есть сайт.

Аналогия Сайт — это как книга, которая лежит в библиотеке. Библиотека работает круглосуточно. Любой человек может прийти, взять книгу и посмотреть. Только вместо книги — твои фотографии, тексты и кнопки.

Сайт состоит из нескольких частей:

  • HTML — это структура. Что где стоит: заголовок, текст, кнопка, фотография.
  • CSS — это внешний вид. Цвета, шрифты, размеры, отступы. Всё, что делает сайт красивым.
  • JavaScript — это движение. Анимации, кнопки, формы, которые реагируют на нажатие.
  • Изображения — фотографии, логотипы, иконки.

Тебе не нужно программировать. Сайт уже свёрстан. Ты просто загружаешь готовые файлы на хостинг — и он работает. Это как собрать мебель по инструкции: все детали уже готовы, нужно только соединить.

Глава 02

Что такое домен и зачем он нужен

Домен — это адрес сайта. Как адрес дома. Например, metaimperiya.com. Когда человек вводит этот адрес в браузере — он попадает на твой сайт.

Аналогия Домен — это как адрес дома. Если у тебя нет адреса, никто не найдёт твой дом. Если у тебя нет домена, никто не найдёт твой сайт.

Домены бывают разные:

  • .com — международный. Лучший вариант, если ты хочешь работать за границей (Америка, Европа). Стоит около 10–15 долларов в год.
  • .ru — российский. Дешевле, но для международной карьеры хуже.
  • .model, .fashion — специальные домены для моделей и fashion-индустрии.
  • .nyc, .la — если ты работаешь в конкретном городе.
Важно: для международной карьеры лучше выбирать .com. Он понятен всем, его легко запомнить, и он вызывает больше доверия у зарубежных клиентов.

Глава 03

Что такое хостинг

Хостинг — это компьютер, на котором лежит твой сайт. Этот компьютер работает 24 часа в сутки, 7 дней в неделю, чтобы сайт был доступен в любое время.

Аналогия Домен — это адрес. Хостинг — это дом, где ты живёшь. Без дома адрес бесполезен. Без хостинга домен ничего не значит.

Хостинг тоже нужно оплачивать. Стоит примерно 5–20 долларов в месяц. Но есть и бесплатные варианты:

Глава 04

Что такое GitHub и Vercel

GitHub — это бесплатное хранилище для файлов сайта. Ты загружаешь туда HTML-код, фотографии, стили — и они там хранятся. GitHub работает как облачная папка, только для кода и сайтов.

Vercel — это сервис, который берёт файлы из GitHub и автоматически публикует их в интернете. Ты просто загружаешь код — и через минуту сайт уже работает. Бесплатно.

Аналогия GitHub — это склад, где лежат твои файлы. Vercel — это магазин, который берёт товары со склада и выставляет их на витрину. Люди приходят в магазин и видят твой сайт.

Как это работает по шагам:

  1. Ты создаёшь аккаунт на GitHub (бесплатно).
  2. Загружаешь туда файлы сайта (index.html и фотографии).
  3. Создаёшь аккаунт на Vercel (бесплатно).
  4. Связываешь Vercel с GitHub.
  5. Vercel автоматически публикует твой сайт.
  6. Ты получаешь ссылку — и можешь её отправить кому угодно.
Плюс: когда ты меняешь файлы на GitHub — Vercel автоматически обновляет сайт. Тебе не нужно ничего делать вручную.
Глава 05

Что такое Firebase

Firebase — это бесплатный сервис от Google, который даёт базу данных, авторизацию и хранение файлов.

Что это значит на практике:

  • База данных — если ты хочешь, чтобы на сайте была форма заявки, Firebase сохраняет эти заявки.
  • Авторизация — если ты хочешь, чтобы у тебя был личный кабинет на сайте, Firebase это делает.
  • Хранение — если ты хочешь добавлять новые фото без правки кода, Firebase их хранит.
Аналогия Firebase — это мозг твоего сайта. Он запоминает, кто пришёл, что заказал, какие фото загрузил.

Для старта Firebase не обязателен. Но если захочешь развивать сайт — он пригодится. Например, чтобы клиенты могли оставлять заявки прямо на сайте.

Глава 06

Что такое Telegram-бот и зачем он нужен

Telegram-бот — это программа внутри Telegram, которая общается с людьми автоматически. Он не спит, не устаёт и работает 24/7.

Что бот может делать для модели:

  • Показывать портфолио — человек нажимает кнопку и видит твои работы.
  • Отвечать на частые вопросы — «Сколько стоит съёмка?», «Как с тобой связаться?».
  • Принимать заявки — человек оставляет имя и телефон, бот сохраняет.
  • Переводить на разные языки — если к тебе обращаются иностранцы.
  • Отправлять информацию тебе в личку — ты сразу видишь новые заявки.
Аналогия Telegram-бот — это личный секретарь, который работает круглосуточно. Он встречает гостей, отвечает на вопросы и передаёт тебе важную информацию.

Как создать бота:

  1. Открой Telegram.
  2. Найди @BotFather — это официальный бот для создания ботов.
  3. Напиши ему /newbot.
  4. Придумай имя и username для бота.
  5. Получи токен — это ключ к боту. Никому его не показывай.
  6. Через конструкторы (Manybot, Puzzlebot) настрой, что бот будет делать.
Связка с сайтом: человек заходит на твой сайт, нажимает кнопку «Открыть Telegram-бота» — и попадает в бота. Так сайт и Telegram работают вместе.
Глава 07

Что такое Render и зачем он нужен

Render — это сервис, который запускает программы в интернете. Если твой Telegram-бот написан на Python, его нужно где-то запустить, чтобы он работал 24/7. Render это делает.

Аналогия Если бот — это робот, то Render — это розетка, в которую он включён. Без розетки робот не работает.

Почему Render:

  • Бесплатный тариф — для старта хватает.
  • Простой — не нужно быть программистом.
  • Автоматический — загружаешь код, Render сам запускает.
  • Надёжный — бот работает 24/7.
Связка: GitHub (код бота) → Render (запуск бота) → Telegram (бот работает). Ты не программируешь — ты просто загружаешь готовый код.

Глава 10

С чего начать прямо сейчас

Если ты начинающая модель, тебе не нужно пытаться сделать всё за один день. Начни с десяти шагов:

  1. Придумай профессиональное имя или псевдоним.
  2. Выбери 2–3 направления моделинга.
  3. Определи визуальный стиль.
  4. Создай профессиональное портфолио.
  5. Зарегистрируй основные социальные сети.
  6. Создай собственный домен.
  7. Сделай официальный сайт.
  8. Начни собирать реальные публикации, интервью и профессиональные упоминания.
  9. Создай Telegram-бота.
  10. Свяжи все площадки между собой.
План на 30 дней: каждый день — один маленький шаг. Через месяц у тебя будет полноценная цифровая экосистема. Не перепрыгивай. Строй последовательно.
