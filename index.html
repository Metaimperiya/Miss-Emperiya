Как это работает

Простыми словами — без программирования

Сайт — это набор файлов (HTML, CSS, картинки), которые лежат на компьютере-сервере. Когда человек вводит адрес сайта в браузере, браузер запрашивает эти файлы и показывает их. Тебе не нужно программировать — сайт уже свёрстан. Ты просто загружаешь файлы на хостинг, и он работает.
Домен — это адрес сайта, как адрес дома. Например, metaimperiya.com. Домены бывают платные и бесплатные. Платные (например, .com) стоят около 10–15 долларов в год. .com — международный домен, он лучше подходит, если ты планируешь работать за границей (Америка, Европа). Российские домены (.ru) тоже есть, но для международной карьеры лучше .com.
Хостинг — это компьютер, на котором лежит сайт. Он работает 24/7, чтобы сайт был доступен в любое время. Хостинг тоже платный — примерно 5–20 долларов в месяц. Но есть и бесплатные варианты: GitHub Pages, Vercel, Netlify. Для старта этого достаточно.
GitHub — это бесплатное хранилище для файлов сайта. Ты загружаешь туда HTML-код, и он там хранится. Vercel — сервис, который берёт файлы из GitHub и автоматически публикует их в интернете. Ты просто загружаешь код — и через минуту сайт уже работает. Бесплатно. Это самый простой способ запустить сайт без затрат.
Firebase — это бесплатный сервис от Google, который даёт базу данных, авторизацию и хранение. Например, если ты хочешь, чтобы на сайте была форма заявки или чтобы можно было добавлять новые фото без правки кода — Firebase это делает. Для старта он не обязателен, но если захочешь развивать сайт — пригодится.
Telegram-бот — это программа внутри Telegram, которая общается с людьми автоматически. Он может показывать портфолио, отвечать на вопросы, принимать заявки. Бот работает 24/7 и не устаёт. Его можно связать с сайтом: человек заходит на сайт, нажимает кнопку — и попадает в бота. Создать бота можно через @BotFather в Telegram. Это бесплатно.
Render — это сервис, который запускает программы в интернете. Если твой Telegram-бот написан на Python, его нужно где-то запустить, чтобы он работал 24/7. Render это делает. Есть бесплатный тариф. Ты просто загружаешь код бота на Render — и он работает.
Мы собираем простую, но рабочую связку:
  • Сайт — на GitHub + Vercel (бесплатно)
  • Данные — на Firebase (бесплатно)
  • Бот — на Python + Render (бесплатно)
  • Домен — платный, около 10–15 долларов в год
Это минимальные затраты, чтобы ты увидела, как всё работает, и поняла, что тебе нужно. Когда захочешь больше — мы сделаем более профессиональную версию.
METAIMPERIYA — это цифровая экосистема для бизнеса, проектов и онлайн-продвижения. Мы создаём сайты, настраиваем Telegram-ботов, помогаем с цифровыми решениями. Твой сайт — часть этой экосистемы. В подвале сайта есть ссылка на METAIMPERIYA.
